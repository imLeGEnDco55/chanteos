## 2026-02-14 - Sensitive Data Visibility
**Learning:** Users often need to verify API keys or passwords after pasting. Hiding them by default is secure, but frustrating without a toggle.
**Action:** Always include a visibility toggle (Eye/EyeOff) for long, complex secrets like API keys to reduce user friction during setup.

## 2026-05-21 - Clearable File Inputs
**Learning:** File inputs that replace their trigger button with the filename create a "trap" state where users cannot easily unselect the file.
**Action:** When a file is selected, always provide a distinct "Clear" or "Remove" action (X button) to allow the user to reset the selection without reloading.
