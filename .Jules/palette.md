## 2026-02-14 - Sensitive Data Visibility
**Learning:** Users often need to verify API keys or passwords after pasting. Hiding them by default is secure, but frustrating without a toggle.
**Action:** Always include a visibility toggle (Eye/EyeOff) for long, complex secrets like API keys to reduce user friction during setup.

## 2026-02-14 - File Input Clearing
**Learning:** Standard file inputs lack an easy "undo" mechanism. Once a file is selected, users often feel trapped without a clear way to remove it without reloading.
**Action:** When a file is selected in a dialog, replace the upload button with a container showing the filename and a dedicated "X" button to clear the selection.
