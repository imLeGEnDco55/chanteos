## 2025-03-09 - High-Frequency Audio State Triggering Expensive Derived Calculations
**Learning:** `SongEditor` rerenders on every audio `timeupdate` (multiple times per second). Deriving state using chained functional methods like `.filter().reduce()` for `totalSyllables` and `lyricLineCount` creates constant unnecessary object allocations and redundant O(n) iterations on the hot path, causing measurable performance degradation. Also, passing inline anonymous functions `() => {}` to memoized children like `PromptLibraryDialog` defeats memoization.
**Action:** Always wrap expensive derived calculations in `useMemo` using single imperative loops when the component is bound to high-frequency state updates like audio playback. Extract static inline functions to module-level constants (e.g., `const NO_OP = () => {};`) to ensure prop stability.
